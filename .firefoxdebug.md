# Firefox Debugging Alternative

If Edge doesn't work, try Firefox (better remote debugging protocol):

## Installation:
```bash
cd ~/.local/share/nvim/lazy/
git clone https://github.com/firefox-devtools/vscode-firefox-debug
cd vscode-firefox-debug
npm install
npm run build
```

## Add to debug.lua:
```lua
-- Firefox adapter
dap.adapters.firefox = {
  type = 'executable',
  command = 'node',
  args = {vim.fn.stdpath('data') .. '/lazy/vscode-firefox-debug/dist/adapter.bundle.js'},
}

-- Firefox configuration
{
  type = 'firefox',
  request = 'launch',
  name = 'Debug: Launch Firefox',
  reAttach = true,
  url = 'http://localhost:5173',
  webRoot = '${workspaceFolder}',
  firefoxExecutable = 'C:/Program Files/Mozilla Firefox/firefox.exe',
}
```

Firefox has better source map support than Chrome/Edge.
